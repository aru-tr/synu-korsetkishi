# Шынының сыну көрсеткішін анықтау

Кітаптағы №5 зертханалық жұмысқа арналған қазақ тіліндегі виртуалды зертхана. Қосымша тәуелділіктерсіз HTML, CSS және JavaScript арқылы жасалған.

## Іске қосу

Осы каталогта:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Браузерде сервердің 8000 портын ашыңыз. `index.html` файлын тікелей ашуға да болады. Сыртқы API, құпия кілт және интернет қажет емес.

## Жұмыс барысы

1. Теория мен кітаптағы нұсқаулықты оқыңыз.
2. Түсу бұрышын және AO = OB ұзындығын таңдаңыз.
3. Төрт қадам арқылы 1–2, 3–4 түйреуіштерін қойып, пластинаны алып, сәуле жолын салыңыз және сызғышты қосыңыз.
4. Транспортир арқылы бұрыштарды қараңыз. AD және CB кесінділерінің мм мәндерін сызбадан оқып енгізіңіз.
5. Басқа бұрышта екінші тәжірибені орындаңыз.
6. n, салыстырмалы және абсолют қателіктерді, қателік аралықтарын салыстырыңыз.
7. Қорытынды мен дәлдікті арттыру ұсыныстарын жазыңыз. Есепті JSON түрінде жүктеңіз немесе басып шығарыңыз.

Модельде n = 1.5, ауада n = 1, параллель беттер идеал. Түйреуіштер дұрыс сәулелерге автоматты қойылады: қолмен сәйкестендіру қателігі модельденбейді. Кесінділер 1 мм дәлдікпен көрсетіледі; ΔAD = ΔCB = 1 мм. ε үлеспен есептеліп, кестеде пайызбен көрсетіледі. Өлшемдер сызбаға сай тексеріледі. Жаңартқанда енгізілген деректер тазаланады; сақтау үшін есепті жүктеңіз.

## Оқушылардың жауаптарын Supabase арқылы қабылдау

Сайт `supabase-config.js` ішіндегі жобаға қосылады. Мұндағы publishable кілт ашық сайтта қолдануға арналған. Secret/service_role кілтін ешқашан қоспаңыз.

### Supabase жобасында бір рет орындау

1. **SQL Editor → New query** бөлімінде [supabase/setup.sql](supabase/setup.sql) файлының толық мазмұнын орындаңыз. Скрипт тек `refraction_reports`, `refraction_teachers` кестелерін және `submit_refraction_report` функциясын баптайды; басқа зертханалардың кестелерін өзгертпейді. Скриптті қайта орындауға болады.
2. Бұрынғы мұғалім аккаунтыңыз бар болса, соны пайдаланыңыз. Болмаса **Authentication → Users → Add user** арқылы өз поштаңыз бен құпиясөзіңізбен аккаунт жасаңыз. Құпиясөзді репозиторийге немесе чатқа жазбаңыз.
3. SQL Editor ішінде өз аккаунтыңызды мұғалім тізіміне қосыңыз (төмендегі поштаны өзіңіздікіне ауыстырыңыз):

```sql
insert into public.refraction_teachers (user_id)
select id from auth.users where lower(email) = lower('YOUR-EMAIL@example.com')
on conflict do nothing;
```

Нәтижеде бір аккаунт қосылғанын тексеріңіз. Бұл рұқсат басқа зертханалардың мұғалім рұқсаттарынан бөлек.

4. Сайттағы **Мұғалім панелі** (`teacher.html`) арқылы кіріңіз. Оқушыларға негізгі `index.html` бетін жіберіңіз.
5. Екі тәжірибе мен қорытындыны толтырып, тест ретінде жауап жіберіңіз. Панельдегі **Жаңарту** батырмасынан кейін жұмыстың келгенін тексеріңіз.

### Деректер және қолжетімділік

- Оқушы аккаунтсыз, аты-жөні мен сыныбын енгізіп жібереді. Қызмет тек толық екі тәжірибені қабылдап, есептеулерді серверде қайта есептейді.
- Аноним пайдаланушылар жауаптарды оқи, өзгерте немесе өшіре алмайды. Оқу рұқсаты тек `refraction_teachers` тізіміндегі кірген аккаунттарға берілген (RLS).
- Жауаптар жеке кестеде сақталады; бір Supabase жобасын бірнеше зертханаға ортақ қолдануға болады.
- Желілік жауап белгісіз болса, сол жіберу ID-сімен қайта жіберіледі: бір жауап қайталанып сақталмайды. Бет жаңартылғаннан кейін қайта жіберу жаңа жұмыс ретінде сақталады.
- Панельде 30 жұмыстан беттеу, сынып бойынша дәл сүзу, өлшеулер және толық қорытынды бар. Токен тек бет жадында сақталады; бетті жаңартқанда қайта кіру керек.
- Ашық жіберу оқушы тұлғасын растамайды. Қажет болса, кейін оқушы аккаунттарын немесе спамнан қорғауды қосуға болады.
